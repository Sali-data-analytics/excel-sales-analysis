# Excel Sales Analysis

## Project Overview

This project analyzes sales data from January to April 2026 using Microsoft Excel. The objective is to answer key business questions, identify revenue patterns, and validate the accuracy of the results.

## Business Questions

1. Which month generated the highest revenue?
2. Which product generated the highest revenue?
3. Which customer generated the highest revenue?

## Key Findings

- March generated the highest monthly revenue: €2,230 (38.8%).
- Laptop generated the highest product revenue: €3,390 (59.0%).
- Customer C04 generated the highest customer revenue: €2,490 (43.4%).
- Revenue decreased to €930 in April, a 58.3% decline compared with March.
- Revenue is concentrated in the Laptop product and Customer C04.
